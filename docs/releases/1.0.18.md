改善聊天流式显示、文件预览和会话切换体验。

Improved streaming chat, file previews, and session switching.

- Reduced repeated work in streaming code highlighting, Markdown parsing, and cached session rendering.
- Source previews use native continuous text views, with file search processed in the background.
- On Mac, text selection and table cell range selection use separate modes, selectable from the table toolbar.
- Missing files offer Create File on the corresponding host. Existing files are never overwritten, and parent directories are not created automatically.
- A new When Returning to a Session preference defaults to Latest Messages, with an option to restore the Previous Reading Position.

- Fixed missing session notifications after switching to another Mac app.

The downloadable package is for Mac; this release does not include a TestFlight upload. Open the DMG and replace Paseo Native in its existing installation folder. Settings and hosts are preserved.

Known issue: tool details freezing on some Macs remains under investigation and is not fixed in this release.
