- Change a worktree's base branch: tap the base branch at the top of the Changes pane, search and pick a new one; changes, commits and Git actions follow the new base.
- Archiving a worktree now checks the host first, so you're warned even when it only has new files or unpushed commits.
- With daemon 0.15.3 or later, you can undo a workspace archive right away, worktrees included (an archive still in progress is canceled; a deleted directory is recreated).
- Fixed the Mac app quitting when opening a video preview.
