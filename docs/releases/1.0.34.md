- Images in sessions can now be saved: right-click (long-press on iPhone/iPad) and choose “Save Image…” or “Copy Image”, or use the save button in the enlarged view (⌘S on Mac). You can also drag an image straight to the Desktop, Finder, or another app. The original image is saved.
- Scheduled runs no longer show up in the sidebar’s session list (thanks to @zhoudagua for PR #8).
