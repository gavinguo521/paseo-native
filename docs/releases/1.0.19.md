Fixes automatic chat scrolling and important replies being collapsed.

- Fixed automatic scrolling that could stop as long replies streamed in or tool cards grew. Scrolling up still preserves your reading position; returning to the bottom resumes following new content.
- Assistant replies in completed turns remain visible, even when another message follows. Earlier conclusions and instructions are no longer hidden inside the activity summary. Tool activity can still be collapsed, in its original reading order.

The downloadable package is for Mac; this release does not include a TestFlight upload. Open the DMG and replace Paseo Native in its existing installation folder. Settings and hosts are preserved.

Known issue: tool details freezing on some Macs remains under investigation and is not fixed in this release.
