Preview interactive pages directly in chat, with improved mobile connection recovery.

- HTML `visualize` markers in assistant replies now render as interactive previews, with expanded viewing and a return to the original conversation.
- File previews have an explicit Return to Conversation button.
- On returning to the foreground, iPhone and iPad check whether the connection is still alive, reconnect when needed, and reload history without retaining errors from the old connection.
- The public source includes the Apple Watch companion, using a paired iPhone to browse sessions, send replies, and answer supported question forms, with bilingual setup instructions and screenshots.

HTML previews currently support self-contained pages with inline styles and scripts. External CDNs, relative resources, and network APIs are not loaded.

The downloadable package is for Mac. iPhone, iPad, and Apple Watch changes are available in source for building and installation with Xcode; this release does not include a TestFlight upload.

Open the DMG and replace Paseo Native in its existing installation folder. Settings and hosts are preserved. Updates are not installed automatically.

Known issue: tool details freezing on some Macs remains under investigation and is not fixed in this release.
