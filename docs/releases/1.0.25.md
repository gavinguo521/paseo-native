修复 iPhone / iPad 多个页面的按钮挤压和窄屏布局问题，并减少不必要的计算与动画。

- 灵动岛汇总复用子会话索引，避免按工作区重复扫描全部会话。

- 运行状态圆圈响应低电量模式、减少动态效果和前后台状态。

Fixes cramped buttons and narrow-screen layouts on iPhone and iPad.

- Separates schedule filters from navigation and action buttons.
- Fixes compressed archived badges and misaligned history separators.
- Improves touch targets and text layouts in session import, command palette, sidebar, and tool details.
- Keeps APNs configuration within the phone screen width.
- Adapts permission and script actions to available width, including shared components on Mac.

- Reuses the subagent index when aggregating Live Activity status.
- Skips inactive-app summary work and periodic agent refreshes while preserving push notifications and token registration.
- Pauses running indicators in Low Power Mode, Reduce Motion, and inactive app states.

The Mac installer is signed and notarized by Apple. iPhone and iPad users can build this release from source with Xcode; no public mobile installation package is provided.
