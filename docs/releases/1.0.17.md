新增链接悬浮菜单、聊天图片同步和手机拍照。

- 链接：Mac 上网页链接显示下划线，悬停、右键或键盘可选择应用内打开、默认浏览器打开或复制链接。
- 聊天图片：手机发送的图片，在其他设备打开同一会话时也能看到。旧版只保存在发送设备内存中的历史图片不会自动迁移。
- 手机拍照：iPhone / iPad 的「＋」菜单新增「相机拍照」，确认后进入草稿。
- 图片草稿：可以点开查看，也可以逐张删除。
- 长会话切换更快。
- 应用内浏览器：网页加载失败时显示原因，可以重试或转到默认浏览器。
- 手机键盘：点击会话空白处或滑动可收起键盘，草稿保留。
- Provider 检测：Codex 等 CLI 装好后不用手动刷新，连上主机、回到前台或打开新建会话时会自动重新检测。
- 历史翻页：到达末尾后隐藏「加载更多」，并恢复实时更新。

本次下载为 Mac 安装包；iPhone / iPad 和 Apple Watch 的变更包含在源码中，需自行使用 Xcode 构建安装。

打开 DMG，将 Paseo Native 拖到原应用所在目录并选择替换，设置和机器列表会保留。更新不会自动安装。

Adds a link hover menu, chat image sync, and camera capture on mobile.

- Links: On Mac, web links are underlined. Hover, right-click, or use the keyboard to open in the app, open in your default browser, or copy the link.
- Chat images: Images sent from a phone now appear when the same session is opened on other devices. Older images kept only in the sending device's memory are not migrated.
- Camera: The iPhone and iPad + menu now includes Take Photo; confirmed photos go to your draft.
- Image drafts: Open draft images to view them, or remove them one at a time.
- Switching between long sessions is faster.
- In-app browser: When a page fails to load, the reason is shown, with options to retry or use your default browser.
- Mobile keyboard: Tap an empty part of the session or scroll to dismiss the keyboard. Your draft is kept.
- Provider detection: After installing a CLI such as Codex, you no longer need to refresh manually. Paseo rechecks when connecting to a host, returning to the foreground, or opening a new session.
- History paging: Load More is hidden at the end of the history, and live updates resume.

The downloadable package is for Mac. iPhone, iPad, and Apple Watch changes are available in source for building and installation with Xcode.

Open the DMG and replace Paseo Native in its existing installation folder. Settings and hosts are preserved. Updates are not installed automatically.
