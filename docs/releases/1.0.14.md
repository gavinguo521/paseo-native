改进原生交互，新增会话总览与表格复制粘贴。

- 会话总览：按状态查看多台机器上的会话，支持搜索、筛选、跳转和待处理请求。
- 工具详情：独立面板查看完整日志和代码改动，支持切换工具记录、复制和跟随实时输出。
- 新回复提示：项目显示新回复数量，点击即可定位，不改变手动排列的项目顺序。
- 表格：支持单格及矩形区域选择，可复制为 Markdown 或电子表格格式；粘贴标准网页表格可转为 Markdown，用户消息也能显示原生表格。纯制表符文本可通过输入框「＋ → 粘贴为表格」转换。
- 性能：改善多项目侧栏、输入和流式消息的响应与滚动体验。
- 更新提醒：运行中每 30 分钟检查，启动和回到前台也按相同间隔检查；同一版本不重复提醒，「以后再说」延后 24 小时，设置页保留下载入口。

下载后打开 DMG，把 Paseo Native 拖进「应用程序」替换旧版，设置和机器列表会保留。更新不会自动安装。

说明：复杂合并单元格和混合正文的 HTML 不强行转表格；App 完全退出后不会检查更新。新的检查周期在安装本版后生效，旧版仍按原周期发现这次更新。

Native interaction improvements, a session overview, and table copy/paste.

- Session overview: browse sessions across hosts by status, search and filter, open conversations, and handle pending requests.
- Tool details: inspect full logs and diffs in a separate panel, navigate between records, copy content, and follow live output.
- New replies: project badges open unread conversations without changing manual project order.
- Tables: select cells or rectangular ranges and copy as Markdown or spreadsheet data. Standard HTML tables can be pasted as Markdown, and user messages now render tables natively. For plain tab-separated text, use “+ → Paste as Table”.
- Performance: improved sidebar, input, streaming response, and scrolling responsiveness with many projects.
- Update reminders: check every 30 minutes while running, and at launch or on returning to the foreground with the same rate limit. Reminders are deduplicated across launches; Later snoozes for 24 hours, and download links remain in Settings.

Open the downloaded DMG and drag Paseo Native into Applications to replace the previous version. Settings and hosts are preserved. Updates are not installed automatically.

Complex merged-cell or mixed-content HTML is left to regular paste. Updates are not checked while the app is fully quit. The new schedule takes effect after installing this version; older clients discover this release on their existing schedule.
