修复侧栏的项目、工作区和会话显示及操作体验。

- 恢复 iPhone 侧栏项目的紧凑间距，保留项目图标。
- 修复 iPhone 返回侧栏后功能按钮残留选中状态，以及再次点击无法进入的问题。
- 空项目展开后显示“新建工作区”入口。
- 工作区行始终显示工作区名称；只有一个会话时直接进入，不再重复展开一行。
- 多会话工作区保留展开入口，展开按钮与打开工作区的按钮独立，改善触屏操作。

Mac 安装包已签名并经苹果公证。iPhone / iPad 暂不提供公开安装包，请使用本版本源码通过 Xcode 编译安装。

Improves sidebar project, workspace, and session navigation.

- Restores compact project spacing on iPhone and preserves project icons.
- Fixes lingering navigation selection and repeated navigation on iPhone.
- Shows a New Workspace action when an empty project is expanded.
- Keeps workspace names on workspace rows. A workspace with one session opens directly without a duplicate child row.
- Preserves expansion for multiple sessions and separates disclosure controls from workspace navigation for reliable touch interaction.

The Mac installer is signed and notarized by Apple. iPhone and iPad users can build this release from source with Xcode; no public mobile installation package is provided.
