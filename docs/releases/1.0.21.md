同步官方 0.15.3 的命令菜单改进，并修复 iOS 文本操作问题。

- 命令菜单增加加载提示和失败重试，减少误操作。
- iOS：修复「选择文本」窗口超出屏幕、文字显示不全的问题。
- iOS：修复粘贴长文本后，收起键盘无法滑到输入框底部的问题。

本版已移除 1.0.20 中误加入的两项未正式发布功能。已安装 1.0.20 的用户请更新到本版。

---

Includes command menu improvements from official v0.15.3 and fixes iOS text interactions.

- Added command loading indicators and retry on failure, reducing accidental actions.
- iOS: Fixed the Select Text sheet extending beyond the screen and clipping text.
- iOS: Fixed scrolling to the bottom of long pasted text after dismissing the keyboard.

This release removes two unreleased features mistakenly included in 1.0.20. If you installed 1.0.20, please update to this version.
