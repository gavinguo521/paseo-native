命令菜单更好用了：输入「/」时会显示加载状态，加载失败可以重试，也减少了误操作。

另外，已为两项官方新功能做好准备：
- 查看正在后台运行的任务，并单独停止。
- 为工作区选择比较代码改动时使用的基准分支。

这两项功能需要官方后续版本的后台服务（daemon）支持，0.15.3 暂时还不能使用。支持后，在运行任务的电脑上更新 daemon 即可。

---

The command menu is easier to use: typing "/" shows a loading indicator, failed requests can be retried, and accidental actions are less likely.

This update also prepares support for two upcoming official features:
- View running background tasks and stop them individually.
- Choose the base branch used to compare changes in a worktree.

These two features require a future official daemon release; version 0.15.3 does not support them yet. Once available, update the daemon on the computer running your tasks.
