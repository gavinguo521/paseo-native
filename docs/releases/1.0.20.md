Fixes text interactions on iPhone and iPad.

- Fixed the Select Text sheet extending beyond the phone screen and clipping content on both sides.
- Fixed unstable scroll bounds in long drafts that could leave the end of the text out of view, including after pasting text and dismissing the keyboard.

The downloadable package is for Mac and has the same Mac functionality as 1.0.19. The iOS fixes are included in the source; no TestFlight build was uploaded.

This version does not include the tool preview and background task detection changes from PR #6. Duplicate Claude reasoning originates in the official daemon; this client update does not apply the server patch.
