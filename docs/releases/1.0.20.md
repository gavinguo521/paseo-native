daemon 版本要求：
官方 v0.15.3 是正式版，但尚不包含上述后台任务管理和基准分支切换接口。这两项适配对齐官方后续开发更新，并非 v0.15.3 已提供的功能。客户端仅在所连接主机的 daemon 明确支持时显示对应入口；旧版 daemon 保留现有行为。最低支持版本须等官方包含这些接口的正式版发布后再确认，仅升级到 0.15.3 不会启用这两项功能。

需要升级的是所连接主机上的 daemon。本机若由本客户端管理，可在「设置 → 机器 → 这台 Mac」中更新；远程主机需分别在对应机器上升级。客户端安装包不会自动升级 daemon。

Improves the command menu and prepares support for background work management and worktree base branch changes in newer official daemons.

- Added command loading indicators and retry on failure. Provider commands take priority; typing only "/" no longer defaults to local actions such as archiving. This improvement requires only a client update.
- Added compatibility for live background work inventories, status updates, and stopping individual tasks.
- Added compatibility for changing a worktree's comparison and merge base without checking out a branch or modifying files.

Daemon requirements:
Official v0.15.3 is a stable release, but it does not include the background work management or base branch APIs above. These two integrations follow subsequent upstream development, not features shipped in v0.15.3. Their controls appear only when the connected daemon advertises support; older daemons retain existing behavior. The minimum supported stable version will be confirmed once upstream releases these APIs. Updating to v0.15.3 alone does not enable them.

Update the daemon on each connected host. For a local daemon managed by this client, use Settings → Machines → This Mac. Remote hosts must be updated separately. Installing this client does not automatically update daemons.

iOS / iPadOS source fixes:
- Fixed the Select Text sheet extending beyond the phone screen and clipping content.
- Fixed scrolling to the end of a long pasted draft after dismissing the keyboard.

This release provides a Mac package. The iOS fixes are source-only; no TestFlight upload is included. The tool preview and background task detection changes from PR #6 are excluded. Duplicate Claude reasoning originates in the official daemon; this client update does not apply the server patch.
