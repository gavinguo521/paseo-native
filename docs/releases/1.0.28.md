优化跨会话消息的来源识别和导航体验。

- 显示发送方的真实工作区名和会话名，跨主机时显示主机名。
- 点击来源可跳转会话，并可返回来源会话、恢复阅读位置。
- 长按或右键可复制会话链接、查看完整名称与状态；Mac 支持在独立窗口打开。
- 主机离线时提供连接入口，会话不在列表时可查询或查看归档历史；查询失败显示实际错误。

Mac 安装包已签名并经苹果公证。iPhone / iPad 暂不提供公开安装包，请使用本版本源码通过 Xcode 编译安装。

---

Improves sender identification and navigation for messages between sessions.

- Shows the sender’s workspace and session names, with the host name for messages from another machine.
- Opens the sending session and provides a return action that restores the source reading position.
- Long-press or right-click to copy a session link or inspect the full name and status. Mac also supports independent session windows.
- Offers reconnection for offline hosts and lookup or history access for sessions outside the current list. Failed lookups show the actual error.

The Mac installer is signed and notarized by Apple. iPhone and iPad users can build this release from source with Xcode; no public mobile installation package is provided.
