修复新建会话打乱侧栏手动排序的问题。

- 手动排序时，在已有项目中新建会话不再把整个项目推到顶部。
- 新工作区和新项目追加到列表末尾，并记住位置；后续新增不会再次打乱顺序。
- 从菜单选择手动排序时，保留切换前看到的顺序。

打开 DMG，将 Paseo Native 拖到原应用所在目录并选择替换，设置和机器列表会保留。若旧版位于其他目录，请替换原来的应用，避免保留两份。更新不会自动安装。

已知问题：部分 Mac 打开工具详情卡死仍在排查，本版未包含该问题的修复。

Fix sidebar manual ordering when creating sessions.

- Creating a session in an existing project no longer moves the project to the top in manual order.
- New workspaces and projects are appended and their positions are remembered.
- Choosing manual order from the menu preserves the currently displayed order.

Open the DMG and replace Paseo Native in its existing installation folder. Settings and hosts are preserved. If the previous app is in a different folder, replace that copy to avoid duplicate installations. Updates are not installed automatically.

Known issue: tool details freezing on some Macs remains under investigation and is not fixed in this release.
