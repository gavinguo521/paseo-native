# 保留回合中的助手正文（#1564）

旧规则把最后一条 assistant_message 之前的正文与操作一起收进整轮摘要。于是重要结论之后补一句等待状态，就会隐藏前面的结论。

新规则只汇总连续的普通工具操作和相邻思考过程；遇到助手正文、计划卡片或上下文压缩提示即结束该段摘要，正文保持可见及原有顺序。最后回复的整轮复制内容、耗时和速度信息继续保留。运行中的回合和完整显示模式沿用原行为。

回归使用“重要结论与操作说明 → 另一个任务还在等待复审”，同时覆盖有/无工具插入、运行中/已完成、分段摘要顺序、唯一标识和整轮复制文本。旧实现单项测试产生 5 个失败断言，证明该案例原本会隐藏重要正文。

这是展示派生逻辑修改，不改变消息数据、协议或持久化。按任务风险自查及针对性验证，未启动独立评审。

验证结果：Mac TimelinePerformanceTests、StreamReplayTests、TimelineBottomFollowTests 共 14 项通过；iOS MobileFeatureTests 1 项通过。未安装到日常 App，实际聊天场景待人工验收；未推送、未发布。
