# Mac Markdown 表格文字选择（#1557）

## 原因及修改

此前表格无条件设置 `.textSelection(.disabled)`，并安装双击选格、高优先级长按拖动区域选择，导致用户无法像正文一样直接拖选单元格里的部分文字。

现在 Mac 默认启用原生文本选择，普通模式完全不安装这两种表格选择手势。工具栏增加“选择单元格区域”：进入后恢复原双击/长按区域选择，选择后可复制 Markdown 或 TSV；点击“完成区域选择”退出并清除区域。整表复制始终可用。辅助功能“选择单元格”会进入区域模式。iOS 维持原有区域选择。

## 验证与限制

- Mac `TableSelectionTests` 和 `TableClipboardTests` 共 7 项通过，包括区域方向、跨行和引用、Markdown/TSV 格式、原生表格布局。
- iOS `MobileFeatureTests` 1 项通过，确认共享表格代码可编译并完成原生布局。
- `git diff --check` 通过；本次只改变本地 UI 手势，没有协议、并发、持久化或安全边界变化，按规则自查，不启动独立评审。
- 尝试原生鼠标拖动与复制的临时测试时，测试宿主无法成为活动应用，窗口始终 `isKeyWindow=false`，第一响应者停在窗口，复制事件不被处理。因此该尝试未证明拖选成功，也未作为通过的测试计数；临时探针位于 `/tmp/paseo-1557-TableTextSelectionTests.swift`，未纳入常规测试套件。
- 未替换当前安装版本。真实桌面上的鼠标拖选仍需人工验收，不能把静态布局/格式测试等同于拖选验收。

## 人工验收步骤

1. 打开含 `E1_VISION=example` 的 Markdown 表格，直接按住鼠标拖过 `E1_VISION`，应出现文字选区；⌘C 后粘贴应只有选中的文字。
2. 双击单元格里的词，应使用原生文字选择，不应直接切为整格选中。
3. 点击“选择单元格区域”，双击一格或长按后拖过多格，使用“复制所选区域”验证 Markdown 与表格格式。
4. 点击“完成区域选择”，区域清除，重新可以拖选文字；整表复制仍可使用。
5. 手机端长按拖动选择区域的行为保持不变。
