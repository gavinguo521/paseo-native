# 工具详情卡死排查（#1547）

2026-11-06 用户反馈：另一台 Mac 的 Paseo Native 1.0.14 (300) 打开工具详情后卡死。用户提供的诊断显示系统 27.0.1，但不包含窗口尺寸、选中工具内容、主线程采样或 SwiftUI 布局诊断。连接日志和 daemon 报错不能据此归因为 UI 卡死。

本机相同版本实机打开两条工具详情后均可关闭；新增 `ToolDetailsLayoutTests` 覆盖完整 Presenter 的选择、布局和关闭，而非仅静态渲染 Panel。测试使用 760 / 960 点容器和短内容；这不是另一台机器或长输出卡死的复现证据。

尚未修改详情生产逻辑。用户已重启故障机器，需再次卡住时通过活动监视器对 Paseo「取样进程」，或提供当时 macOS 保存的无响应报告，以确定阻塞调用。原始诊断含个人环境信息，不复制到仓库。
