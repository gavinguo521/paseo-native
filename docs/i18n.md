# 界面本地化（中文源语言 + 英文）

## 机制

- 源语言是简体中文，翻译在 String Catalog：App 用 `App/Resources/Localizable.xcstrings`，灵动岛扩展用 `Widgets/Localizable.xcstrings`，PaseoKit 用 `PaseoKit/Sources/PaseoKit/Resources/Localizable.xcstrings`。key 就是中文原文。
- 编译时 Xcode 自动收集文案；命令行用 `xcodebuild -exportLocalizations -project Paseo.xcodeproj -localizationPath <目录> -exportLanguage en -skipPackagePluginValidation` 导出 xliff，填好英文后 `-importLocalizations` 导回。
- 运行时跟随系统语言；Mac「系统设置 → 通用 → 语言与地区 → App」、iOS「设置 → Paseo → 语言」可单独给本 App 选语言。

## 哪些会自动翻译（不用改代码）

SwiftUI 控件的参数**直接写字符串字面量**时，类型是 `LocalizedStringKey`，会自动收集和翻译，包括带插值和三元表达式的：

```swift
Text("新聊天")
Button("切回官方 App…") { … }
Text("发现新版本 \(r.version)")            // key：发现新版本 %@
Button(method == "direct" ? "连接并添加" : "添加")
Label("复制", systemImage: "doc.on.doc")
Toggle("自动检查更新", isOn: $auto)
.navigationTitle("看板")
```

## 哪些要改写（子代理的工作）

文案先变成 `String` 再显示的，**不会**被翻译。`Text(someString)`、`Button(someString)`、`Label(someString, …)` 收到 `String` 变量时按原样显示。改法：在**文案产生的地方**用 `String(localized:)` 包起来，中文原文一字不改：

```swift
// 计算属性 / 函数返回 String
private var title: String {
    switch status.owner {
    case .official: return String(localized: "由官方 Paseo App 运行")
    ...
}

// 带插值
return String(localized: "现在有 \(runningHere) 个会话正在运行，会被中断。")   // key：现在有 %lld 个会话正在运行，会被中断。

// 赋给 String 属性 / 传给 String 参数后再显示
step = String(localized: "停止官方 App 的 daemon")
problem = String(localized: "看板服务没有响应：\(reason)")
throw Failure(String(localized: "npm 安装失败：\(output)"))
Banner(level: "error", message: String(localized: "连接已断开"))

// 字典 / 数组里的显示名
[("history", String(localized: "会话历史")), ...]

// 三元表达式结果是 String（不是直接写在控件参数里）
let label = done ? String(localized: "已完成") : String(localized: "进行中")
```

- **PaseoKit 里**（Swift Package）必须带 bundle：`String(localized: "连接超时", bundle: .module)`。
- 拼接出来的句子（`"共 " + n + " 个"`）改成一整句带插值的 `String(localized: "共 \(n) 个")`，不要分段翻译。
- 插值里的值本身如果是要显示的中文（比如状态名），那个值也要在它产生的地方本地化。
- 给翻译者的提示：同一个中文在不同地方意思不同时，用 `String(localized: "打开", comment: "菜单项：在访达中打开文件")` 加 comment。一般不用加。

## 哪些不要动

- 注释、日志（`print`、`os_log`、`Logger`）、`#if DEBUG` 里只给开发者看的文案（如 DebugLegend）。
- 诊断报告 `DiagnosticsReport` 的内容（发给开发者看的，保持中文）。
- 作为数据用的字符串：UserDefaults 的 key、协议字段值、和 daemon 输出做比较 / 匹配的字符串、正则、文件名、URL、SF Symbol 名。
- 已经是 SwiftUI 字面量的地方（见上一节），不要画蛇添足改成 `String(localized:)`。
- 发给 agent 的提示词（会话里要发给模型的文字）：保持原样。
- 不改任何逻辑、不改中文原文、不改格式化和换行之外的东西。
