# #1559 切回会话位置设置

设置 → 聊天 → 切回会话时：
- 最新消息（默认）：页面出现时清除旧恢复偏移和历史窗口，调用既有返回最新逻辑。
- 上次阅读位置：沿用现有阅读位置恢复条件。

设置持久化到本机 UserDefaults，Mac/iOS 共用界面。未改变流式消息更新时的自动滚动逻辑，用户在当前会话上翻阅读不会因此被新消息强制拉回底部。

## 验证

TimelinePerformanceTests 新增恢复策略测试：默认最新、有效旧位置、失效首行、历史窗口、原本底部、无记录。独立静态评审通过。Mac 编译及 TimelinePerformanceTests/StreamReplayTests 共 11 项通过；iOS 编译及 FileSourceTests/MobileFeatureTests 共 2 项通过。测试包含原生时间线布局回放，但没有模拟真实侧栏点击切换。

尚未安装到日常 App；人工验收步骤：长会话上翻→切到另一会话→切回，默认应显示最新；设置为上次阅读位置后重复，应保留原阅读位置。设置为最新后再次切回，应离开旧历史窗口并显示最新。
